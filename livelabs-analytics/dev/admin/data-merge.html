Step 2 · Map records

Choose the matching fields

Use the same identifier in both sources where possible. Ambiguous and unmatched rows stay out of the applied merge.

matches

Match rule: trimmed, case-insensitive exact values. WMS IDs can identify multiple Analytics records; ambiguous matches need a different field. Jenkins Error Score: 100 × burden ÷ (burden + 20), where burden = (P2 occurrences × 2) + P3 occurrences. P1 stays in the urgent action queue. Ranked scores blend the existing Analytics score with the Jenkins score.
