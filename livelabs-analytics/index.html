Example + explanation
Practical example

Retire-Now ranking needed more eligible rows

What happened: the strict rule did not produce enough rows, so the process widened the search one controlled step at a time. It stopped at weighted_v4 when it had 8 usable rows.

1strict_v1
Start with the narrowest retirement conditions.Not enough rows
2weighted_v2
Try the first weighted fallback.Still not enough
3weighted_v4
Broaden low demand slightly; allow confirmed or review replacement; require content older than 12 months.Used: 8 rows

Practical meaning: the dashboard did not skip the strict rule. It only relaxed the approved conditions after earlier steps were insufficient, and it still kept the result as a review queue rather than an automatic retirement decision.

How to read the example

What each highlighted step means

Used in order
1
strict_v1 is always tried first.

This protects the result from becoming broader than necessary. If it finds enough eligible rows, the process stops there.

2
weighted_v2 is a controlled widening step.

It changes only the approved fallback conditions. It does not replace the identity, evidence, or active-content checks.

3
weighted_v4 is the first step that produced enough rows.

In this example, it allows a slightly broader demand threshold, accepts a confirmed or review replacement, and still requires content older than 12 months.

4
Fallback does not mean automatic retirement.

The selected rows remain a governed review queue. A person still confirms the evidence and the final action.
